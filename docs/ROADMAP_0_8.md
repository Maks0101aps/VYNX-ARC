# План VYNX ARC 0.8.0

Статус: **кандидат 0.8.0 проверен автоматическими воротами и реальным
обновлением 0.7.0 → 0.8.0; ручные ворота и решение по памяти 7Z открыты**.
Базовая версия — принятый 0.7.0 (`v0.7.0`, коммит `fbe1f34`). Этот план
фиксирует конкретные цели 0.8.0 и не заменяет общий контракт V1.

## Границы выпуска

- 0.8.0 завершает локализацию, клавиатурную/экранную доступность, типизацию
  очереди операций, воспроизводимость измерений и повторную приёмку пакетов.
- Гарантии безопасности 0.7.0 сохраняются без ослабления: исходный архив не
  перезаписывается, ACL/read-only отказ публикуется немедленно, MOTW и
  отпечатки источников проверяются, незавершённые рабочие копии защищены.
- Создание RAR **не входит** в 0.8.0. `bitplane/rars` — читатель RAR, а не
  компрессор; имитация RAR-записи запрещена. Поддерживается существующее
  чтение RAR4/RAR5 и создание остальных заявленных форматов.
- Push, тег и публикация релиза выполняются только по отдельному указанию.

## 3. Типизированная очередь и журнал — P0

- [x] `JobKind`, `JobState`, `ModifyAction`, `ArchiveFormat`,

- [x] Сравнения вида операции и состояния в журнале, повторе и диспетчере

- [x] Неизвестные значения ограничиваются безопасными значениями по умолчанию.

  протоколу, а не к выбору операции или состояния в диспетчере.

## Критерий завершения

Автоматические ворота исходников и пакетов пройдены; 0.8.0 считается полностью
принятым только после закрытия ручных ворот Narrator/чистой машины,
человеческой выборочной проверки переводов и решения по росту памяти при
создании 7Z. Извлечение 1000 мелких файлов повторно проверено (+4.9%, +21% не
воспроизвелось) и остаётся под наблюдением. До закрытия оставшихся ворот
статус — **release candidate**, не публичный релиз.
