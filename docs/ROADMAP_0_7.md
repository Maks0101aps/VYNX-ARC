# План VYNX ARC 0.7.0

Status: **0.7.0 принят 2026-10-23**. Все шесть направлений реализованы и
проверены, включая устранение блокера замены ZIP. Незавершённые пункты
первоначального плана перенесены в 0.8.0 (см. конец документа).

База: `v0.6.0`, коммит `c4c99ea`.

## Цель 0.7.0

Открыть вложенный архив, выбрать файлы, скопировать их в другой архив и восстановить прерванную работу — в одном понятном интерфейсе.

---

## 1. Вложенные архивы — P0

- [x] Открытие архива внутри архива двойным щелчком или клавишей Enter.
- [x] Навигация по понятной цепочке хлебных крошек (`backup.zip › documents.7z › contracts/`).
- [x] Извлечение вложенного контейнера в изолированное хранилище `NestedStore` с ограничением максимальной глубины (до 4 уровней) и размера (до 256 МиБ).
- [x] Сохранение связи с родительским архивом: переход назад по клику на родительский архив или кнопками Назад/Вверх.
- [x] Определение устаревания открытой копии при модификации родительского архива (`fileFingerprint` проверка).
- [x] Поддержка просмотра и извлечения из вложенного архива.
- [x] Предсказуемая обработка зашифрованных и повреждённых вложенных архивов.
- [x] Автоматическое освобождение временных данных при закрытии вкладки или отмене.

---

## 2. Копирование между архивами — P0

- [x] Выделение файлов в одной вкладке и копирование в другую через Ctrl+C / Ctrl+V и перетаскивание (drag-and-drop).
- [x] Диалог `InterArchiveCopyDialog`: отображение назначений, конфликтов имён, требуемого места и доступного дискового пространства.
- [x] Выбор политики конфликта имён: Замена (Replace), Переименование (Rename / keep both, `file (1).ext`), Пропуск (Skip).
- [x] Запись в ZIP и 7Z через проверенный механизм модификации с контролем публикаций и журналом.
- [x] Проверка неизменности источника во время операции через снимок контрольного отпечатка (`sourceFingerprint`).
- [x] Полное сохранение исходного архива без удаления (копирование).

---

## 3. Восстановление распаковки — P0

- [x] Формирование и сохранение в журнале структурированного плана распаковки (`recoveryPlan`) со списком файлов, размеров и меток времени.
- [x] Диалог `ExtractionRecoveryDialog` при просмотре / повторе прерванного задания из очереди.
- [x] Сверка состояния назначения на диске: завершено, отсутствует, изменено пользователем, частичный файл / требует проверки.
- [x] Продолжение распаковки только после проверки источника и уже извлечённых данных.
- [x] Защита пользовательских файлов: файлы, изменённые пользователем после распаковки, никогда не перезаписываются.
- [x] Безопасная очистка временных `.tmp` файлов перед повторным извлечением.

## 4. Быстрый повторный просмотр — P1

- [x] Ограниченный по памяти LRU-кеш предпросмотра `PreviewCache` (до 32 МиБ) в сессии архива.
- [x] Мгновенная отдача результатов из кеша при повторном открытии того же файла без запуска дочернего рабочего процесса.
- [x] Сброс кеша при модификации или перезагрузке архива.
- [x] Замер фаз операции (подготовка, декодирование, передача результата).

## 5. Завершённое управление с клавиатуры и временными данными — P1

- [x] Полный сценарий работы без мыши: порядок Tab, стрелки, Enter, Backspace, Alt+Left, Alt+Up, Ctrl+Tab / Ctrl+Shift+Tab, Ctrl+W, F5, F3, F2, Delete, Menu / context menu.
- [x] Доступные подписи (`setAccessibleName`, `setAccessibleDescription`) для всех элементов управления, таблиц и диалогов.
- [x] Раздельный учёт дискового пространства для предпросмотров (`ExternalFiles`), вложенных архивов (`NestedStore`) и рабочих копий (`EditStore`) через `TempStore`.
- [x] Диалог `TemporaryStorageDialog` с предварительным списком очистки (`previewCleanupList`).
- [x] Отображение статусов несохранённых правок и причин удержания данных на диске; рабочие копии защищены от автоматической очистки.
