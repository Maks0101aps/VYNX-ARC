# WIM & ESD Windows Imaging Format Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement full Windows Imaging Format (`.wim`, `.esd`, `.swm`) support (Browse, Test, Extract, and Metadata Inspection) with multi-image index navigation in VYNX ARC v1.0.5.

**Architecture:** A pure Rust structured parser reads WIM header magic (`MSWIM\0\0\0`), flags (XPRESS, LZX, LZMS), lookup resource table, and UTF-16LE XML metadata (image names, descriptions, architecture, file counts). Extraction leverages native Windows `wimgapi.dll` (dynamically loaded from System32) and lookup table SHA-1 verification within bounded worker sandboxes.

**Tech Stack:** Rust 2024, Windows `wimgapi.dll` dynamic bindings, CXX FFI, C++20, Qt 6 Widgets, Inno Setup 6.

**Spec:** [docs/ROADMAP_POST_1_0.md](file:///c:/Users/Maksi/Documents/projects/VYNX-ARC/docs/ROADMAP_POST_1_0.md)

## Global Constraints

- Windows 10/11 x64 target platform; MSVC toolchain.
- Zero external crate dependencies (pure safe Rust parser + standard Windows `wimgapi.dll` dynamic loading).
- Strict fail-closed security: all entry paths must pass `crate::security::validate_name()`.
- Maximum directory depth bounded at 64 levels.
- Read-only archive format (`archive.writable == false`); WIM creations/modifications rejected.
- All code must pass `cargo test --workspace`, strict Clippy (`-D warnings`), and CTest.

## Review Focus

1. **Truncated/corrupt WIM headers (size < 208 bytes, invalid XML offset past EOF):** Must return `ArcError::new("CORRUPT", ...)` and never panic.
2. **Missing or unsupported `wimgapi.dll` calls:** Must fail-closed gracefully with clear error messages, without crashing or memory leaks.
3. **Multi-image index representation:** Multiple images inside a single WIM (e.g. Home, Pro) must be cleanly partitioned into index virtual roots (`[1] Windows 11 Home/`, `[2] Windows 11 Pro/`) or index-based navigation so extraction never collides.
4. **Path traversal in WIM filenames (`..\` or `/` in directory records or XML):** Must be caught and rejected by `crate::security::validate_name()`.
5. **ESD (LZMS solid compression) handling:** When handling `.esd` files, decompression parameters must be appropriately passed to native extraction callbacks without memory blowout.

use std::io::{Cursor, Seek, SeekFrom, Write};
use vynx_arc_core::{Operation, wim};

fn make_synthetic_wim() -> Vec<u8> {
    let mut data = vec![0u8; 1024];
    // Magic: MSWIM\0\0\0
    data[0..8].copy_from_slice(b"MSWIM\0\0\0");
    // Header size: 208 (0xD0)
    data[8..12].copy_from_slice(&208u32.to_le_bytes());
    // Version: 0x00010d00
    data[12..16].copy_from_slice(&0x00010d00u32.to_le_bytes());
    // Flags: 0x00000002 (Compressed)
    data[16..20].copy_from_slice(&2u32.to_le_bytes());
    // Part number: 1, Total parts: 1
    data[40..42].copy_from_slice(&1u16.to_le_bytes());
    data[42..44].copy_from_slice(&1u16.to_le_bytes());
    // Image count: 1
    data[44..48].copy_from_slice(&1u32.to_le_bytes());

    // XML data at offset 512, size 256
    let xml = "<WIM><IMAGE INDEX=\"1\"><NAME>Test Image</NAME><TOTALBYTES>100</TOTALBYTES><FILECOUNT>1</FILECOUNT></IMAGE></WIM>";
    let xml_u16: Vec<u8> = xml.encode_utf16().flat_map(|u| u.to_le_bytes()).collect();
    let xml_offset = 512u64;
    let xml_len = xml_u16.len() as u64;

    // XML resource descriptor in header (offset 72..96)
    // 8 bytes original size, 8 bytes flags (0x02 uncompressed in resource), 8 bytes offset
    data[72..80].copy_from_slice(&xml_len.to_le_bytes());
    data[80..88].copy_from_slice(&0x02u64.to_le_bytes());
    data[88..96].copy_from_slice(&xml_offset.to_le_bytes());

    data.resize(512 + xml_u16.len(), 0);
    data[512..512 + xml_u16.len()].copy_from_slice(&xml_u16);
    data
}

#[test]
fn test_wim_detect_and_header() {
    let raw = make_synthetic_wim();
    let mut cursor = Cursor::new(raw);
    assert!(wim::detect(&mut cursor).expect("detect"));
    let op = Operation::default();
    let (entries, total_size) = wim::list(&mut cursor, std::path::Path::new("test.wim"), &op).expect("list");
    assert!(!entries.is_empty());
}
