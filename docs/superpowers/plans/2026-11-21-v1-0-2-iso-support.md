# ISO 9660 & UDF Disc Image Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement full optical disc image (`.iso`) support (Browse, Test, Extract, and Instant Preview) with Joliet UCS-2BE Unicode directory trees in VYNX ARC v1.0.2.

**Architecture:** A pure Rust zero-allocation sector reader parses ISO 9660 Primary and Supplementary (Joliet) Volume Descriptors starting at sector 16 (offset 32768). Uncompressed sector extents stream directly into existing bounded verification pipelines without intermediate temp files or virtual drive mounting.

**Tech Stack:** Rust 2024, CXX FFI, C++20, Qt 6 Widgets, Inno Setup 6.

**Spec:** [docs/ROADMAP_POST_1_0.md](file:///c:/Users/Maksi/Documents/projects/VYNX-ARC/docs/ROADMAP_POST_1_0.md)

## Global Constraints

- Windows 10/11 x64 target platform; MSVC toolchain.
- Zero external crate dependencies for ISO parsing (pure safe Rust in `core/src/iso.rs`).
- Strict fail-closed security: all entry paths must pass `crate::security::validate_name()`.
- Maximum directory depth bounded at 64 levels to prevent recursive directory cycle attacks.
- Read-only archive format (`archive.writable == false`); modifications/additions rejected.
- All code must pass `cargo test --workspace`, strict Clippy (`-D warnings`), and CTest.

## Review Focus

1. **Truncated/corrupt ISO images (file smaller than 32 KiB or LBA extent past EOF):** Must return `ArcError::new("CORRUPT", ...)` and never panic.
2. **Circular directory loops (directory record pointing back to an ancestor):** Must abort when recursion/depth exceeds 64 levels with `ArcError::new("LIMIT", "Directory hierarchy exceeds maximum depth")`.
3. **Path traversal attacks in Joliet UCS-2BE names (`..\` or `/root`):** Must be caught and rejected by `crate::security::validate_name()`.
4. **Empty directories and 0-byte regular files:** Must preserve directory flags and extract cleanly without hanging or I/O errors.
5. **Joliet Unicode vs ISO 9660 PVD precedence:** When Supplementary Volume Descriptor (Type 2) is present, Joliet UCS-2BE long filenames must take precedence over 8.3 uppercase ASCII PVD names.

use std::io::{Cursor, Seek, SeekFrom, Write};
use vynx_arc_core::{Operation, iso};

fn make_synthetic_iso() -> Vec<u8> {
    let mut data = vec![0u8; 32768 + 2048 * 4];
    // Sector 16: PVD at 32768
    let pvd = &mut data[32768..32768 + 2048];
    pvd[0] = 1; // PVD
    pvd[1..6].copy_from_slice(b"CD001");
    pvd[6] = 1; // Version
    // Root directory record in PVD at byte 156
    let root = &mut pvd[156..156 + 34];
    root[0] = 34; // length
    root[2..6].copy_from_slice(&18u32.to_le_bytes()); // extent LBA 18
    root[10..14].copy_from_slice(&2048u32.to_le_bytes()); // length 2048
    root[25] = 0x02; // directory flag

    // Sector 17: SVD Joliet
    let svd = &mut data[32768 + 2048..32768 + 4096];
    svd[0] = 2; // SVD
    svd[1..6].copy_from_slice(b"CD001");
    svd[6] = 1;
    svd[88..91].copy_from_slice(b"%/@"); // Joliet escape sequence
    let svd_root = &mut svd[156..156 + 34];
    svd_root[0] = 34;
    svd_root[2..6].copy_from_slice(&18u32.to_le_bytes());
    svd_root[10..14].copy_from_slice(&2048u32.to_le_bytes());
    svd_root[25] = 0x02;

    // Sector 18: Root directory sector
    let dir = &mut data[32768 + 4096..32768 + 6144];
    // Record 1: file test.txt at LBA 19, size 5 bytes ("HELLO")
    let name_utf16: Vec<u8> = "test.txt".encode_utf16().flat_map(|u| u.to_be_bytes()).collect();
    let rec_len = (33 + name_utf16.len() + 1) & !1;
    dir[0] = rec_len as u8;
    dir[2..6].copy_from_slice(&19u32.to_le_bytes());
    dir[10..14].copy_from_slice(&5u32.to_le_bytes());
    dir[25] = 0; // regular file
    dir[32] = name_utf16.len() as u8;
    dir[33..33 + name_utf16.len()].copy_from_slice(&name_utf16);

    // Sector 19: File content "HELLO"
    let file_sector = &mut data[32768 + 6144..32768 + 8192];
    file_sector[0..5].copy_from_slice(b"HELLO");

    data
}

    assert_eq!(entries.len(), 1);
    assert_eq!(entries[0].name, "test.txt");
