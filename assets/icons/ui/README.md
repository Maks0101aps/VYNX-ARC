# VYNX utility icons

Original 24-unit vector geometry with 1.6-unit rounded strokes. SVG sources are
kept here; the same paths are drawn by the cached QIconEngine in IconProvider.cpp.
The native renderer follows the current palette and scales through QPainter,
including disabled states, without requiring an SVG plugin or a scene graph.
There are nine cached icon objects, not a widget or asset copy for each table row.
